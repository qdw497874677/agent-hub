# 画布维度缩放（canvas scopes）——设计稿

状态：草案，只有设计，还没有实现。

## 目标

同一块画布可以按三种范围看，并且能在三者之间放大/缩小：

| 范围 | 显示什么 | 怎么分组 |
|---|---|---|
| 项目 `project` | 项目、它的全部任务和会话（就是现在的画布） | 按 worker 分框（#106） |
| 任务 `task` | 一个任务，加上从它派生和分叉出来的会话 | 按 worker 分框；分叉的连线保留 |
| worker `worker` | 一台 worker 上的全部会话，可以跨项目 | 外层是项目框，里面按任务分组；可以切换成「按任务」（任务框，标注项目名） |

## 交互

- **面包屑**放在画布顶栏：`worker › 项目 › 任务`。点任一段就缩回那一层；最右一段是当前范围。从项目进来时，worker 段显示为「全部 worker」，可以点开选一台。
- **范围切换器**：面包屑右边一个分段控件「项目 / 任务 / worker」，选不了的范围置灰（比如没选任务时的「任务」）。
- **放大到任务**：双击任务卡（派生会话已经只走「＋ 会话」按钮，双击空出来了），或者点任务卡顶栏的 `→` 按钮（触屏和键盘用户靠这个）。
- **放大到 worker**：点 worker 框标题栏上的 `→`，双击标题栏也行（单指拖标题栏仍然是拖整框）。
- **缩小**：点面包屑，或者用浏览器后退。
- 换范围时保留各范围自己的视口和布局；布局还是按 (范围, id) 存。

## URL

范围能直接用 URL 打开，前进/后退也正常：

- `#/p/:projectId/canvas`：项目，同现在
- `#/p/:projectId/canvas/t/:taskId`：任务
- `#/w/:workerId/canvas?group=project|task`：worker

如果 URL 指向没有权限或者不存在的对象，退到用户能看的上一层，并给一条提示。

## 权限（RBAC）

- 服务端加 `GET /api/canvas?scope=task&id=` 和 `GET /api/canvas?scope=worker&id=&group=`，过滤规则和项目画布一样：只返回调用者能看的项目里的任务和会话。
- worker 视图：用户能用这台 worker（自己的，或者团队共享的），**并且**能看会话所在的项目，两个条件都满足才显示。看不了的会话只计一个数，显示为「另有 N 条会话无权查看」，不泄露标题。
- 没有新的写接口；拖动、派生、发消息还走原来的接口和权限检查。

## 手机

- 面包屑收成一个下拉标题（显示当前一段，展开是整条路径）；切换器放进底部抽屉。
- 不靠双击：任务卡和框标题栏上的 `→` 常驻显示（和「＋ 会话」一样）。
- worker 视图的项目框默认折叠成一行摘要（项目名 · N 条会话 · 运行中 M 条），点开再展开。

## 和现有交互分区的关系

沿用 docs/guide.md「画布交互分区」：
- 双击任务卡 = 放大到任务（新的）；
- 双击会话卡 = 打开会话（不变）；
- 框可以嵌套（worker 视图里是项目框套任务分组），只有最内层框的标题栏能拖；拖外层框，里面的一起走；
- 会话卡只能在自己的框里拖。

## 决定

1. 一共三种范围：项目、任务、worker。不做「团队」范围（以后需要再加）。
2. 放大到任务的手势：双击任务卡加 `→` 按钮；去掉「双击派生」（已经在画布交互那个 PR 里去掉了）。
3. worker 视图里默认按项目分组，可以切换成按任务分组；跨项目的时候一定画项目框。
4. URL 能直接打开每个范围；没有权限就退到上一层，不报 404。
5. 只读聚合走新的 `GET /api/canvas` 范围参数，服务端做 RBAC 过滤；看不了的会话只计数。
6. 布局按 (范围, id) 分开存，互不影响。
7. 手机上用常驻的 `→` 按钮和下拉面包屑，不靠双击。
