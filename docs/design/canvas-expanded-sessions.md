# 画布中展开会话（多窗口）——设计稿

状态：草案，只有设计，还没有实现。和 #111（画布维度缩放）配套。

## 目标

在画布里把会话卡「展开」成一个大窗口：能看完整对话、能用完整输入框，大小合适，**可以同时开好几个**并排看。不用离开画布进对话视图（`…/focus/<会话>`）。

## 窗口是什么

- 窗口是**浮在画布上面的一层**（屏幕坐标），不是 React Flow 的节点：画布平移、缩放时窗口不动、不跟着变小，字始终清楚。会话卡留在原处，标一个「已展开」角标。
- 窗口内容直接复用对话视图的组件：`FocusView` 拆出 `SessionPane`（消息流 + `chat-blocks` + `Composer` + 停止/分叉/继续到别处），对话视图和窗口共用，行为（滚到底、作者显示、等待回复状态 `waitingForReply`）保持一致。
- 窗口标题栏：会话名 · 状态点 · worker 名；按钮：最小化 `–`、最大化 `□`、进对话视图 `↗`、关闭 `×`。

## 怎么打开

- 会话卡顶栏加「⤢ 展开」按钮（触屏常驻）。
- 快捷：选中会话卡后按 `Enter` 或空格。
- 双击会话卡仍是「打开会话」（进对话视图），不变；见决定 1。

## 默认大小和摆放

按画布可视区（扣掉顶栏、右下控件）自动平铺，开几个就分几格，不重叠：

| 打开数 | 布局 |
|---|---|
| 1 | 居右，宽 `min(720px, 55%)`，高 `100% − 边距`；左边留出画布，看得到卡片 |
| 2 | 左右两列 |
| 3 | 左 1 大 + 右 2 小，或三列（宽屏 ≥1600px） |
| 4 | 2×2 |
| ≥5 | 只平铺最近聚焦的 4 个，其余自动最小化到底部窗口条 |

- 每格最小 `360×320`；放不下就减少格数，多出的最小化。
- 用户拖动标题栏或拖右下角改大小后，该窗口变为「自由摆放」，不再参与平铺；工具栏「⊞ 重新平铺」恢复。
- 浏览器窗口变化时按比例重新算（存的是相对可视区的比例，不是像素）。
- 布局计算写成纯函数 `tileWindows(viewport, windows) → Rect[]`，放 `layout.ts` 旁边，单测覆盖。

## 多窗口：焦点、层级、最小化、关闭

- 点窗口任意处 = 聚焦，置顶（z 顺序是一个按最近聚焦排序的数组）；聚焦窗口边框高亮，对应会话卡也高亮。
- 键盘：`Esc` 关当前窗口；`Ctrl/⌘ + [` / `]` 在窗口间切换焦点。
- 最小化：收到底部「窗口条」，一个窗口一枚标签（名称 + 状态点；有新回复、等待回复时有提示点）。点标签恢复。
- 关闭只关窗口，不影响会话；运行中的会话照常跑。
- 上限默认同时展开 8 个（流的订阅成本），超出时最早的最小化窗口被关闭并提示。
- 每个打开（非最小化）窗口各订阅一条 SSE；最小化只保留轻量状态订阅（已有的画布状态流），恢复时再拉对话。

## 记住打开的窗口

- 存浏览器 `localStorage`，按「账号 + 画布范围（#111 的 scope + id）」分键：`agent-hub:canvas-windows:<user>:<scope>:<id>`，内容是 `[{sessionId, mode: tiled|free|min|max, rect(比例), z}]`。
- 刷新后恢复；会话已删除、进了回收站或已无权限的，静默丢掉。
- 不写服务端：这是「怎么看」，和显示设置一样是本机偏好；见决定 3。
- URL 不带窗口列表（太长），只带当前聚焦的一个：`…/canvas?win=<会话>`，方便发链接直接展开。

## 和交互分区、画布范围的关系

在 docs/guide.md「画布交互分区」表里新增：

| 区域 | 做什么 |
|---|---|
| 窗口标题栏 | 拖动窗口（屏幕坐标，不动画布） |
| 窗口对话区 | 只滚动、选文字；滚轮不缩放画布 |
| 窗口右下角 | 改窗口大小 |
| 窗口以外的画布 | 原有行为不变（平移、缩放、点卡选中） |

- 窗口层整体 `nowheel nopan nodrag`，事件不冒泡到 React Flow。
- 窗口不会挡住画布控件：平铺区域排除右下角控件和左下图例。
- 和 #111：每个范围各自记一份窗口集合；切范围（面包屑、双击任务卡放大）时换成该范围的窗口。窗口里的会话不在新范围里时，自动最小化而不是关闭；回到原范围恢复。
- 卡片单击选中、拖卡、「＋ 会话」等全部不变。

## 手机（窄屏 / 触屏）

- 一次只显示一个，**全屏**（等于嵌在画布里的对话视图），顶部一条：`‹ 画布` 返回、会话名、`1/3` 计数。
- 左右滑（在标题条上滑，不在对话区里，避免和滚动、选字冲突）切换到下一个打开的窗口；也可以点计数弹出列表切换。
- 返回画布后底部显示窗口条（横向滚动的标签），点哪个开哪个。
- 不支持自由摆放和改大小。

## 分层（六边形）

- **领域（纯函数，无 React）**：`canvas-windows.ts`——窗口集合状态与操作 `open / focus / minimize / maximize / close / moveFree / retile`，`tileWindows()` 布局，上限与淘汰规则，范围切换时的过滤。全部单测。
- **端口**：`WindowStore`（读写持久化）；实现 `LocalStorageWindowStore`，测试用内存实现。
- **适配器 / UI**：`CanvasWindows` 层组件（拖动、缩放用成熟库 `react-rnd`，或沿用项目已有的 React Flow `NodeResizer` 风格自己写——见决定 4），`SessionPane` 复用对话视图。
- 服务端：无新接口；发消息、停止、分叉都走原接口与 `can()` 权限检查。窗口恢复时对无权会话按 404/403 丢弃。

## 测试

- 单测：平铺（1–6 个、各种可视区、最小尺寸回退）、z 顺序、淘汰、持久化往返、范围切换过滤。
- e2e（1280 / 390 宽）：开 3 个窗口不重叠；在两个窗口分别发消息互不串；对话区滚轮不缩放画布；刷新后恢复；手机全屏与滑动切换；关闭窗口会话继续运行。
