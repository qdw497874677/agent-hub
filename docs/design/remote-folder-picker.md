# 远程文件夹选择器

选择的是已选机器上的目录，不是浏览器所在设备的目录。沿用 Worker 返回的允许位置、目录列表和创建能力；打开选择器不扫描其他机器，也不替用户选择路径。

## 参考与取舍

- [iPad「文件」：查找和浏览](https://support.apple.com/guide/ipad/find-and-view-files-and-folders-ipadb3b759ed/ipados)：先确定位置，再浏览；查找保留明确范围。借这一分工，不照搬本机、云盘等位置分类。
- [VS Code Remote-SSH](https://code.visualstudio.com/docs/remote/ssh)：先选择远程机器，再用熟悉的文件浏览方式打开目录。机器在上一级启动表单选定，选择器只展示当前机器，不再放第二个机器下拉框。
- [Finder「前往文件夹」快捷键](https://support.apple.com/en-us/102650)：路径直达是独立操作。保留粘贴完整路径的快入口，但不劫持 Tab，也不用退格键返回上一级。

## 操作约定

- 入口打开后先显示当前机器和目录，可从托管位置出发，也可在该机器获准访问的其他位置间切换。触屏打开时不弹键盘。
- 点文件夹只进入下一级；返回上一级、粘贴路径、显示隐藏项和新建文件夹各有独立操作。进入或新建都不等于确认选择。
- 用固定的「选此文件夹」确认已经读取成功的当前目录。加载、离线或权限错误时，不能把上一次的列表、旧路径或输入草稿当作本次选择。
- 取消不修改启动配置；确认后回填原表单，不替用户启动会话。长期工作目录登记和会话启动复用同一个选择器。
